
# Практическая работа №1

## Расчёт стоимости покупки

Консольное приложение на языке Python.

Программа позволяет:
- Вводить название товара.
- Указывать цену и количество.
- Рассчитывать стоимость покупки.
- Рассчитывать скидку 5%, 10% или 15%.
- Определять сумму до следующего уровня скидки.

## Запуск программы

python main.py
