
# Практические работы №1 и №2

## Вариант 4. Расчёт стоимости покупки

Консольное приложение на языке Python для расчёта
стоимости покупки с учётом скидок.

## Практическая работа №1

Реализованные возможности:

- Ввод названия одного товара.
- Ввод цены и количества товара.
- Расчёт стоимости покупки.
- Автоматический расчёт скидки.
- Определение суммы до следующего уровня скидки.

## Практическая работа №2

Добавленный функционал:

- Возможность добавлять несколько товаров.
- Хранение списка товаров.
- Расчёт стоимости каждого товара.
- Подсчёт общей стоимости покупки.
- Применение скидки к общей сумме.
- Проверка правильности введённых данных.
- Проверка ответа при добавлении нового товара.

## Система скидок

- От 5000 рублей — 5%.
- От 10000 рублей — 10%.
- От 15000 рублей — 15%.

## Запуск программы

```bash
python main.py
```
