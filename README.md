# Практические работы №1, №2 и №3

## Вариант 4. Расчёт стоимости покупки

Консольное приложение на языке Python для расчёта стоимости покупки одного или нескольких товаров с учётом скидок.

## Практическая работа №1. Разработка консольного приложения

Реализованные возможности:
- Ввод названия товара, цены и количества.
- Проверка корректности введённых данных.
- Расчёт общей стоимости покупки.
- Автоматический расчёт скидки.
- Вывод итоговой стоимости с учётом скидки.
- Расчёт экономии на одной единице товара.
- Определение суммы до следующего уровня скидки.

Автоматические скидки:
- От 5 000 до 9 999,99 — 5%.
- От 10 000 до 14 999,99 — 10%.
- От 15 000 — 15%.

## Практическая работа №2. Работа с Git и развитие приложения

Добавлена возможность рассчитывать стоимость покупки нескольких товаров.

Реализованные возможности:
- Последовательное добавление нескольких товаров.
- Ввод названия, цены и количества каждого товара.
- Проверка введённых данных.
- Вывод списка добавленных товаров.
- Расчёт общей стоимости всей покупки.
- Применение автоматической скидки к общей сумме.
- Определение суммы до следующего уровня скидки.

Для хранения версий программы используется Git и удалённый репозиторий GitHub.

## Практическая работа №3. Аргументы командной строки и обработка исключений

Добавлена возможность управлять программой через аргументы командной строки с помощью библиотеки `argparse`.

Реализованные возможности:
- Передача названия товара и цены через позиционные аргументы.
- `--quantity` — указание количества товара.
- `--discount` — установка скидки вручную в процентах.
- `--currency` — выбор валюты RUB, USD или EUR.
- `--verbose` — вывод подробного расчёта.
- `--help` — справочная информация.
- Обработка ошибок с помощью `try-except`.
- Запись ошибок в файл `errors.log`.

Журнал ошибок содержит дату и время, тип ошибки, описание и информацию об операции, при выполнении которой возникла ошибка. Новые записи добавляются без удаления предыдущих.

## Запуск программы

Для запуска необходим установленный Python 3.

### Интерактивный режим

```bash
python main.py
```

Программа последовательно запрашивает данные и позволяет добавлять несколько товаров.

### Запуск через командную строку

```bash
python main.py "Мышь" 2000 --quantity 2 --discount 5
```

Пример результата:

```text
Товар: Мышь
Цена: 2000.00 RUB
Количество: 2
Общая стоимость: 4000.00 RUB
Скидка: 5%
Размер скидки: 200.00 RUB
Итоговая стоимость: 3800.00 RUB
```

### Подробный расчёт

```bash
python main.py "Клавиатура" 4500 --quantity 2 --discount 10 --currency USD --verbose
```

Аргумент `--currency` изменяет обозначение валюты, но не выполняет конвертацию по обменному курсу.

### Справка

```bash
python main.py --help
```

## Проверка обработки ошибок

Пример ввода некорректной цены:

```bash
python main.py "Мышь" -100 --quantity 2
```

Пример некорректного количества:

```bash
python main.py "Мышь" 2000 --quantity 0
```

Пример некорректной скидки:

```bash
python main.py "Мышь" 2000 --quantity 2 --discount 150
```

При возникновении ошибок программа выводит сообщение пользователю и записывает информацию в `errors.log`.
